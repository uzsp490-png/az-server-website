ASHZONE SERVER RULES

伺服器規章與風險聲明

為了確保所有玩家都能擁有健康、友善且公平的遊戲環境，請所有倖存者務必詳閱並遵守以下規範。

違反規則者，管理團隊將依情節進行警告、處分、停權或移除伺服器資格。

01
MOD SERVER

模組伺服器與風險聲明

AshZone 為 DayZ 模組伺服器。由於 DayZ 本體、模組環境及伺服器更新機制的特性，遊戲過程中可能發生：

  • 遊戲崩潰 / 伺服器故障
  • 資料不同步 / 斷線 / 延遲
  • 模組衝突 / 模組更新異常
  • 功能錯誤 / 重啟後資料異常
  • DayZ 引擎造成的非預期問題
資料遺失與補償

因 DayZ BUG、模組更新、伺服器重啟、不同步、斷線、延遲、模組錯誤或非管理人為因素造成的物品、載具、金錢或資料遺失，原則上不予補償。

僅在管理團隊確認為重大且明確的系統錯誤時，才可能依實際情況介入處理。

02
PLAYER CONDUCT

玩家行為與社群規範

  • 禁止使用外掛、作弊程式或非法輔助工具。
  • 禁止惡意利用 BUG、漏洞或非正常機制取得利益。
  • 禁止欺騙、詐騙、冒充管理員或惡意破壞他人遊戲體驗。
  • 禁止惡意辱罵、騷擾、挑釁、持續引戰或破壞社群秩序。
  • 禁止散布其他玩家位置、基地資訊或私人糾紛。
  • 未經允許，禁止於非隊員基地內下線。
03
REPORT & SUPPORT

投訴、問題回報與 Discord 規範

若對伺服器、功能、模組、其他玩家、管理人員或工作人員有問題、疑慮、爭議或檢舉，請使用官方客服中心、工單、LINE 或 Discord 指定客服管道。

  • 請勿在公共頻道持續發布抱怨、爭吵、引戰或針對性不滿言論。
  • 影響社群秩序的公共貼文可能被刪除，恕不另行通知。
  • 所有 Discord 頻道皆需遵守 Discord 社群規範。
  • 禁止惡意攻擊、騷擾、洗版、引戰與破壞社群氣氛。
04
PVE / PVP

PVE、PVP 與偷竊規則

PVE 區域
  • 全面禁止偷竊。
  • 禁止偷竊玩家物品與載具。
  • 禁止惡意破壞其他玩家財產。
PVP 區域
  • 允許一般偷竊行為。
  • 禁止偷竊商城裝備。
  • 禁止偷竊商城載具。

其他 PVP、活動、殺戮日及抄家規則，依當期官方公告為準。

05
BASE & TERRITORY

基地與領地規則

禁止建設區域

  • 貿易區 500 公尺內。
  • 軍事基地 / 軍事路障 500 公尺內。
  • 交易區 / 任務點 / 載具刷新點。
  • 警察局 / 消防局 / 醫療大樓。
  • 自訂地圖區域（非原版區域）。

基地建設限制

  • 禁止橫跨或阻塞主要道路。
  • 城鎮、村莊、工業區禁止額外加蓋大型建築，僅允許依規定加設必要的門。
  • 禁止利用地形或原始建築藏匿物品與載具。
  • 禁止浮空基地。
  • 禁止使用保險箱作為門或牆。
  • 禁止惡意堆疊木箱、門、艙口、大門等活動部件。
  • 玩家必須能正常進出基地所有區域。

數量與高度

  • 基地高度不得超過 3 層與 100 公尺。
  • 每個團體 / 小隊最多 2 個基地 / 領地。
06
VEHICLES

載具規則與風險

DayZ 載具本身可能發生飛車、卡車、不同步、碰撞異常、瞬移或零件異常損壞。使用載具須自行承擔相關風險。

  • 每個群組 / 領地最多停放 6 輛載具。
  • 每個領地可申請 1 個停車樁。
  • 超過規定數量的載具，管理團隊可直接刪除且不另行通知。
  • PVE 區域禁止偷竊任何載具。
  • PVP 區域依當期伺服器規則執行。
  • 商城載具不得偷竊。
載具傷害

車輛碰撞可能造成電瓶、火星塞、水箱等零件損壞。時速超過 30 km/h 發生碰撞時，可能造成車體或零件損傷。

RPM 長時間超過紅線時，引擎可能受損。引擎損壞後仍可能有約 50% 機率發動。

07
SAFEZONE

安全區與交易者營地規則

  • 禁止駐紮。
  • 禁止使用火堆。
  • 禁止埋藏任何物品。
  • 禁止阻擋道路、商人或交易停車格。
  • 禁止使用擴音器騷擾其他玩家。
  • 禁止偷竊其他玩家物品或載具。
  • 禁止長時間將載具停放於交易者營地加油區。
安全區載具停放

載具於安全區停留超過 3 小時，管理團隊可移至管理車庫保管。

若載具遭移至管理車庫，僅保證載具本體存在，車內物品及內容物不在保管範圍內。

08
HELICOPTER

直升機相關

目前直升機不啟用傷害。後續若有調整，以官方公告為準。

09
VEHICLE FEATURES

車輛功能與限制

  • 支援拖車功能。
  • 載具無法使用撬鎖方式強制開鎖。
  • 可使用螺絲起子更換車輛鎖。
10
ADMIN DECISION

管理判定

管理團隊處理爭議時，將依伺服器紀錄、玩家提供之證據、截圖、影片、系統紀錄與實際事件狀況綜合判定。

依事件嚴重程度，管理團隊保留警告、資源回收、功能限制、暫時停權、永久停權或移除伺服器資格之權利。

最後提醒

請所有玩家理解 DayZ 模組伺服器本身具有一定不穩定性。遇到問題時，請優先透過官方客服管道處理，不要在公共頻道引戰或擴大爭議。

感謝各位倖存者配合並共同維護 AshZone 良好的遊戲環境。
