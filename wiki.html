GETTING STARTED

如何加入 AshZone

  1. 加入 Discord
  2. 訂閱 Workshop Collection
  3. 啟動 DayZ Launcher
  4. 搜尋 AZ SERVER

模組安裝

建議使用官方 DayZ Launcher 自動處理模組相依與更新。

安全區

交易與整備區域，禁止偷竊與惡意行為。
