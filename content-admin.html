官網內容管理

選擇你 GitHub Desktop 使用的官網資料夾後，就能直接修改內容。

不會連到你的伺服器主機。 這個工具只會修改你親自選擇的本機官網資料夾。修改完成後，到 GitHub Desktop Commit → Push origin 即可上線。
公告管理讀取 js/news.js，並自動偵測舊版 main.js 注入公告；儲存後統一移入 news.js。
首頁彈窗直接管理 js/announcement.js，可控制開關、標題與內容。
商城管理管理商品、圖片、贊助積分方案與注意事項，全部直接寫入 shop.html。
最快操作： 選擇官網資料夾 → 修改公告或商品 → 按「全部儲存」→ GitHub Desktop Commit → Push origin。

統一管理所有公告。若偵測到舊版 main.js 注入公告，也會一起顯示並在儲存後搬入 news.js。

選擇左側公告，或新增一則公告。

管理商品、圖片、贊助積分方案與商城注意事項。

選擇官網資料夾後即可編輯商城頁資訊。

使用說明

第一次使用只需要認得你的網站根目錄。

官網資料夾要選哪個？
請選擇裡面同時看得到 index.html、shop.html、js、assets 的那一層。

公告儲存位置
js/news.js。舊版寫在 js/main.js 的自動注入公告會在第一次儲存時自動搬入。

首頁彈窗儲存位置
js/announcement.js

商城儲存位置
shop.html；商品、贊助積分方案與商城注意事項都會寫入此頁，新圖片會放到 assets/shop/。

上線方式
完成後打開 GitHub Desktop，看 Changes → Summary → Commit to main → Push origin。
